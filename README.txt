MEDICINE REMINDER (Android, Java)

1. Unzip this folder.
2. Android Studio -> File -> Open -> select the "MedicineReminder" folder (the one containing settings.gradle).
3. Wait for "Gradle sync" to finish (internet needed the first time).
4. Create/choose an emulator (API 26 or higher) or plug in a phone with USB debugging.
5. Press the green Run button.
6. Allow notifications when asked.
